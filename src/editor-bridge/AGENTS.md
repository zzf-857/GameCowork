# Editor bridge scope

Follow the project AGENTS.md. This directory is GameCowork's own editable Unity UPM source, including stable Unity-generated `.meta` asset identities. Do not copy or install the original Codely bridge or modify the original application, Hub records, user projects, licenses or account state.

All editor tests use a unique project under `F:\AI\AgentMake\temp\GameCowork\tests\editor-bridge-*`. Logs, Library, fixture scenes, compiler output and browser artifacts stay there. Use only an installed editor's existing license; a license failure is a failed/blocked live gate, not authorization to activate or log in. Cleanup verifies only the exact self-spawned editor PID and project path.

Keep per-stream ownership: at most six actual captures and 16 compound slots, immutable bounded latest-frame bytes, independent IDs/dimensions/input/leases, and selected actual editor instance identities. Compound receivers are namespaced by compositeId. Shared editor windows close only if created by the bridge and their final capture holder explicitly stops; lease expiry keeps windows open. Unsupported window slots must have honest reasons and must never be filled with mock editor UI.

Network listeners bind only loopback, retain capability-path/Origin checks and bounded requests, and never call a Provider or the original service. Unity API and render-object work stay on the editor main thread. Frames must come from actual EditorWindow GUIView content or the explicit legacy SceneView/GameView render-content fallback, have finite limits and a consumer lease, and be released without closing existing user editor windows. The generic editor-window capture mode must preserve real window chrome, actual Editor DPI and input coordinate offsets; declared capability metadata must match the implemented mode. Do not replace live frame/input evidence with mock video, HTML facsimiles, HTTP success or a transport-connected status.

Run the affected source compilation and actual editor/preview gate after changes: `node tests/integration/editor-bridge-smoke.mjs`. The source/API compilation, true editor rendering/input, concrete preview canvas, and full product routing are distinct claims. Document remaining unsupported views, multi-project/concurrent viewport behavior, WebRTC and audio accurately in the leaf README and append evidence to the existing project RESTORE_STATUS.md; do not create a parallel status document.

Parallel/shared-window changes also run `node tests/integration/editor-bridge-multistream.mjs`; product entry/layout/lifecycle changes run `node tests/e2e/editor-preview-e2e.mjs` with a maintained-source-matching guarded own CLI. Read-only editor tool handlers use real Unity APIs on the main thread and do not start an authenticated model. An unimplemented listener/provider returns supported:false/listening:false; unknown tool/action returns an error, never a synthetic success.

Reload/routing changes run `node tests/e2e/editor-domain-reload-e2e.mjs` and `node tests/e2e/editor-multi-project-e2e.mjs`. Preview start/stop/status and replies retain the originating workspace key/root and cancellation generation, and same-origin iframe snapshots retain their exact sender. A reload of A must never reconnect to the active B, and closing A during reload must never reopen it. The multi-project backend/receiver gate uses two actual independent editor processes; it must not be described as the product's multi-project slot selector unless that actual single-GUI selection/layout has also passed its own live gate.

The actual one-GUI cross-project selector/layout gate is `node tests/e2e/editor-multi-project-ui.mjs`; `--packaged` uses the assembled app paths and verifies normal/guarded Agent source identity. Fit/private texture work must preserve real source aspect without changing user camera/game resolution. Input uses the verified content rectangle; blackbars must never inject into editor content. Retain each fixed project identity in preferences, never capability URLs or temporary PIDs. A saved missing project stays missing rather than resolving against the active chat workspace.
